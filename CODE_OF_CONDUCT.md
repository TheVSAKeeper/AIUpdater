# Правила общения

Обсуждай проблему и код, уважай время участников и оставляй достаточно сведений для воспроизведения ошибки.
Критика решений приветствуется, если она помогает понять проблему и предложить исправление.

В обсуждениях недопустимы оскорбления, травля, дискриминация, угрозы и публикация чужих персональных данных.
Не размещай рекламу и повторяющийся контент, не связанный с проектом.

Если обсуждение нарушает эти правила, укажи на конкретный комментарий владельцу проекта
[TheVSAKeeper](https://github.com/TheVSAKeeper). На публичный комментарий также можно пожаловаться средствами GitHub.
Владелец может скрыть нарушающий правила контент, закрыть обсуждение или ограничить участие.
